Add Another Active Agent Without Replacing This One

A second active agent needs its own config path and its own running process. This guide keeps that separate from "reconfigure this instance" so the current agent is not overwritten by accident.

One Telegram account can own multiple aliases, but two agents online at the same time should run as separate Herd instances. In practice, that usually means a separate bot token per active agent instance.

Use any name you want. Herd will keep this current instance untouched and point the new one to its own config path.

Use a separate env file too, so the new setup does not inherit the current agent alias, scope, bot token, and Telegram settings from the first instance.

Herd cannot start a second local process directly from this browser page. The commands below are only copied, not executed.
